SIFT Evidence Desk

Code retrieves facts • Gemma 4 interprets evidence • Humans decide

EVIDENCE-FIRST PULL REQUEST TRIAGE

Triage pull requests with receipts.

A fast, evidence-based triage assistant for open-source maintainers. Gemma 4 reads unified diffs, extracts verifiable facts, and drafts replies. You decide what merges.

PROCESS

How It Works

STEP 1

Fetch facts

Retrieves raw unified diffs, file lists, and authentic PR context directly from GitHub without profiling contributor identity.

STEP 2

Gemma reads the evidence

Gemma 4 synthesizes findings and extracts verbatim quotes. In-code substring verification audits quotes against raw diffs.

STEP 3

You decide

Inspect highlighted receipts in the dossier, check blindspots, and copy draft responses. Sift never auto-posts comments.

INTEGRITY CONTRACT

Maintainer Principles

⚖

Nothing is posted automatically

Never auto-closes, merges, labels, or comments on pull requests. Only human maintainers initiate GitHub actions.

🔍

Every quote is verified in code

Every citation must match an authentic substring of the retrieved source. Unverified quotes are quarantined immediately.

🤝

New contributors are never penalized

Zero contributor profiling or scoring bias. First-time contributors and one-line typo fixes are evaluated with equal objective care.

§

Locked Invariants (Non-Negotiable)

1
Human-in-the-Loop Supremacy: Suggestions only; maintainers initiate all actions.
2
Zero Contributor Bias: No author scoring, profiling, or penalty for new contributors.
3
In-Code Quote Verification: Substrings checked strictly; unverified quotes quarantined.
4

Secrets & Security: No tokens or API keys committed, logged, or exposed.
